EIDOLON — delegations

← mission control

Generate identity

An Ed25519 keypair for a principal or an agent. The signing key is shown once — store it safely.

Mint delegation

Sign a bounded, revocable credential from a principal's signing key. Authority not granted here is denied.

Attenuate delegation

Derive a strictly-narrower child credential (subset scope/classes/window). Never widens authority.

Revoke delegation

Immediately revoke a credential by id. The next action under it is denied.
